v1.4 additions (also CC0 1.0, Poly Haven, fetched directly from dl.polyhaven.org; no API used)
-----------------------------------------------------------------------------------------------
The trees and the grass are not shipped as 3D models: each was rendered OFFLINE (three.js, lit from the sun direction of the sky photo, with the model's
own diffuse + normal textures) into 8 azimuth views and packed into an alpha atlas ("impostor"); only the resulting images are in this folder.
The Poly Haven models do not carry the artist name in the files that were downloaded; the artist credit is on each asset page below.

The two tree atlases were re-packed in the v1.4 audit from the same offline renders (cell height 512 -> 384 px, transparent gutters below and
beside every cell so that mip levels bleed less between neighbouring views); the views themselves are unchanged.

bark_1024.jpg is now only used as the fallback when the tree atlases cannot be fetched (it is not requested otherwise).

ambientCG (https://ambientcg.com, also CC0) is not used in this version.
The leaf texture of the fallback trees is generated at run time (canvas) and is not a downloaded asset.
The ground's large-scale soil mottling and the soft tree shadows are also generated at run time (value noise + ellipses into a 1024x1024
texture) and are not downloaded assets.
